1. Fixes Implemented

1
<meanOfPayment typeCode="CARD"/> removed from getQuote (CC/POA flow) As requested, this tag has been removed. The CC getQuote now sends only the reservation parameters, with no MOP tag.
2
Double getQuote in ETO flow — resolved The issue was caused by a price-comparison call (without MOP) running in parallel with the ETO getQuote. 3
search.searchbyid implemented (On Request handling) After bookReservation, if statusCode="R" is returned, the system saves the reservation as "On Request", extracts the onRequestItemList, displays a dedicated "Pending Confirmation" screen to the customer, and exposes the search.searchbyid endpoint for status polling.
